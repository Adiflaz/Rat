​🛡️ PlutoX-RAT: Advanced Android Remote Administration Tool

​PlutoX-RAT adalah platform kontrol jarak jauh berbasis web yang dirancang untuk mengelola dan memantau perangkat Android secara real-time. Tool ini menyediakan antarmuka dashboard yang intuitif untuk mengakses data sensitif dan mengontrol fungsi perangkat dari mana saja.

​🚀 Fitur Utama (Berdasarkan Modul Web)
​Berikut adalah kapabilitas utama yang tersedia dalam panel kontrol ini:

​📱 Monitoring Perangkat & Sistem

1.​Device Info (device.html, info.html): Memantau spesifikasi hardware, status baterai, dan informasi sistem operasi target.

2.​App Management (apps.html): Melihat dan mengelola daftar aplikasi yang terinstal di perangkat.

3.​Remote Console (remote.html): Terminal kontrol untuk mengirim perintah eksekusi ke perangkat.

​📁 Akses Data & Log

Communication Logs (calls.html, sms.html): Mengakses riwayat panggilan masuk/keluar serta pesan teks (SMS).

​Contact Discovery (contacts.html): 1.Mengambil seluruh daftar kontak yang tersimpan.

2.​Keylogging (keylogs.html): Mencatat setiap ketikan keyboard (seperti password dan pesan) yang dilakukan pengguna.

3.​Location Tracking (location.html): Melacak koordinat GPS perangkat secara akurat.

​🛡️ Autentikasi & Notifikasi

1.​Login Portal (login.html, index.html): Sistem keamanan panel untuk memastikan hanya admin yang bisa mengakses dashboard.

2.​Push Notifications (notifications.html): Menerima alert atau pemberitahuan instan saat target melakukan aktivitas tertentu.
